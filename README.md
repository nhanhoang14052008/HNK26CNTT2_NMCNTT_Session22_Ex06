# BÀI THỰC HÀNH: KHẮC PHỤC LỖI GIT

## 1. Prompt AI theo công thức 3 thành phần

- **Role:** Bạn là chuyên gia lập trình Git và GitHub.
- **Context:** Tôi gặp lỗi `error: open(".git/FETCH_HEAD"): Permission denied` khi đẩy code lên GitHub.
- **Task:** Hãy giải thích lỗi dễ hiểu, hướng dẫn cách khắc phục bằng Run as Administrator và cảnh báo các rủi ro có thể xảy ra.

## 2. Thực hiện khắc phục

Mở Terminal bằng quyền **Run as Administrator**, vào thư mục dự án và thử lại thao tác Git. Chụp ảnh màn hình trước và sau khi sửa lỗi, khoanh vùng thông báo lỗi và che thông tin cá nhân.

## 3. Tin nhắn nhờ giảng viên hỗ trợ

**Em chào thầy/cô ạ!**

Em đang gặp lỗi khi đẩy code lên GitHub:

- **Context:** Em sử dụng Git trên Windows.
- **Expected:** Đẩy code lên GitHub thành công.
- **Actual:** Terminal báo lỗi `Permission denied` tại file `.git/FETCH_HEAD`.
- **Log:** Em đã chụp ảnh màn hình lỗi và đính kèm.

Em đã thử chạy lại Git bằng quyền Run as Administrator nhưng vẫn chưa khắc phục được.

Mong thầy/cô hướng dẫn em cách sửa lỗi. Em cảm ơn thầy/cô ạ!

## 4. Kết luận

Em đã biết cách sử dụng Prompt AI để tìm giải pháp và báo cáo sự cố theo Bug Reporting Framework gồm 4 thành phần: Context, Expected, Actual và Log.
